# 🌐 Language Exchange & AI Tutor Telegram Bot

Telegram-бот для языкового обмена (Language Exchange) с функцией поиска реальных собеседников и встроенным AI-репетитором для практики английского языка.

---

## 🚀 Основные возможности

* **Matching System:** Поиск случайного собеседника для практики языка в реальном времени.
* **AI Fallback / AI Tutor:** Если собеседник не найден или пользователь хочет заниматься соло — подключается AI-репетитор.
* **Система профилей и рейтинга:** Учет статистики разговоров, оценок и отзывов.
* **Feedback & Reports:** Возможность оставить отзыв о разговоре или пожаловаться на неадекватного пользователя.
* **Admin Dashboard:** Статистика по отзывам, жалобам и активным сессиям в реальном времени.

---

## 🛠 Технологический стек

* **Language:** Python 3.10+
* **Framework:** `aiogram 3.x` (асинхронная библиотека для Telegram API)
* **Database:** SQLite + `aiosqlite`
* **AI Integration:** OpenAI API / Gemini API (для AI Fallback)
* **Environment & Config:** `python-dotenv`
