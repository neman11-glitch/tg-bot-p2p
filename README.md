# LangScope — Telegram-бот для практики английского

Бот платформы LangScope: AI-репетитор для разговорной практики, профиль и статистика, обратная связь. Поиск живого собеседника (P2P) есть в коде, но **по умолчанию выключен**.

---

## Возможности

* **AI-репетитор** — диалог на английском с учётом уровня пользователя. Работает через Groq API (модель `openai/gpt-oss-120b`). Действуют лимиты на пользователя и общий дневной лимит; функцию можно выключить переменной `AI_ENABLED=0`.
* **Профиль и статистика** — уровень, тема, рейтинг, число диалогов.
* **Обратная связь** — оценка и комментарий по категориям; повторный одинаковый отзыв в течение 10 минут не сохраняется.
* **Приватность** — `/privacy` (что хранится и куда передаётся) и `/delete_me` (удаление своих данных).
* **Администратор** — статистика отзывов и жалоб, бан и разбан, ежедневная сводка по сайту LangScope (только итоговые цифры).
* **P2P-поиск собеседника** — выключен (`P2P_ENABLED` не задан). Включать только после мер безопасности для несовершеннолетних: возрастные ограничения, правила, жалоба и блокировка в чате.

Защита: оценки и жалобы привязаны к сессиям диалога, повторно доставленные обновления Telegram обрабатываются один раз, действует общий лимит сообщений на пользователя.

---

## Технологии

* Python 3.11+, `aiogram 3.30`
* База данных: PostgreSQL (Supabase, отдельная схема `bot` и роль с правами только на неё) через `asyncpg`; без `DATABASE_URL` — локальный SQLite для разработки
* AI: Groq API (`groq`)
* Хостинг: Render (long polling + HTTP health check на `/health`)

---

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `ADMIN_ID` | числовой Telegram ID администратора |
| `DATABASE_URL` | адрес Postgres без пароля; если не задан — SQLite |
| `DB_PASSWORD` | пароль роли базы данных (отдельно от адреса) |
| `GROQ_API_KEY` | ключ Groq; без него AI-репетитор недоступен |
| `AI_ENABLED` | `0` — выключить AI-репетитора |
| `AI_USER_LIMIT_PER_10MIN`, `AI_USER_LIMIT_PER_DAY` | лимиты AI на пользователя |
| `USER_RATE_LIMIT_PER_MIN` | общий лимит сообщений на пользователя (по умолчанию 30) |
| `P2P_ENABLED` | `1` — включить поиск собеседника (не рекомендуется) |

Секреты хранятся только в настройках хостинга или в локальном `.env`, который не попадает в репозиторий.
